# 实验五：大模型智能复盘与学习规划验收清单

## 实验目标

将大模型能力与系统内真实学习数据结合，完成可追溯、可解释、可安全使用的智能复盘和学习计划功能，而不是提供脱离业务数据的通用聊天框。

## 已完成功能

- [x] 后端代理调用 DeepSeek，API Key 不进入浏览器端。
- [x] 使用当前官方 Chat Completions 接口和 `deepseek-flash` 模型。
- [x] 支持最近 7 天、14 天、30 天三个分析周期。
- [x] 可按单个学习目标生成，也可汇总全部目标进行阶段复盘。
- [x] 学习计划必须关联明确目标，避免生成空泛建议。
- [x] 自动汇总学习记录数、有效时长、完成任务数与平均专注度。
- [x] 仅向模型发送学习数据，不发送用户名、邮箱、密码等身份信息。
- [x] 使用 JSON Output，并在后端完成结构校验、数量限制和行动时长校正。
- [x] 显式关闭不必要的思考模式，减少结构化 JSON 被推理内容挤占或截断的风险。
- [x] 对未配置密钥、密钥失效、请求过频、连接超时和空响应提供明确提示。
- [x] 成功结果写入 `ai_report` 表，可查看或删除最近 20 份历史报告。
- [x] 单目标报告中的行动建议可一键加入任务计划，并标记为 AI 生成。
- [x] 尊重个人中心的“AI 个性化”开关，关闭时不允许发送数据。
- [x] 页面支持移动端、键盘焦点和减少动态效果偏好。

## 接口说明

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/ai/reports` | 查询当前用户历史报告 |
| `POST` | `/api/ai/reports/REVIEW` | 生成阶段复盘 |
| `POST` | `/api/ai/reports/PLAN` | 生成学习计划 |
| `DELETE` | `/api/ai/reports/{id}` | 删除自己的历史报告 |

生成请求示例：

```json
{
  "goalId": 1,
  "days": 7,
  "note": "下周要进行阶段测验，希望加强薄弱内容。"
}
```

## 安全与隐私设计

1. `DEEPSEEK_API_KEY` 只由 Spring Boot 后端读取。
2. 本地启动脚本使用隐藏输入，不将密钥写入配置文件。
3. `.gitignore` 排除 `.env` 与本机环境文件。
4. API 请求由当前 JWT 用户身份确定数据范围，不能指定其他用户。
5. 模型输出只是学习建议，页面明确要求用户确认后再执行。
