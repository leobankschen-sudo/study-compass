## 本轮接口验收

- 学习记录新增、列表、日期区间查询、单项查询、更新、删除均通过。
- 学习记录与用户、目标、任务之间存在归属校验。
- 开始日期晚于结束日期时返回 HTTP 400。
- 前端通过 `/api/records` 代理读取 MySQL 数据成功。
- 首页的任务完成率、本周投入、连续学习、逾期任务、目标进度和周节奏均由真实数据计算。
- 个人资料与学习偏好查询、更新通过；非法学习时长和时段返回 HTTP 400。
- 顶部昵称和头像由 Pinia 用户状态驱动，资料保存后即时同步。
